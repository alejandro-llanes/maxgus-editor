maxgus

A very small Emacs, written in Rust. Emacs keys, tree-sitter highlighting, a language-server client, magit and a file tree — in a terminal, or in a window.

$ curl -fsSL https://alejandro-llanes.github.io/maxgus-editor/install.sh | sh

Installs the full build. Add -s -- --build gui for the window, --build minimal for the small one.

What is in it

Emacs keys, and Doom's

The classic bindings, and Doom's leader scheme under C-c. Prefix arguments, keyboard macros, registers, rectangles, the mark ring.

which-key new

Pause mid-sequence and a panel says what can follow it, so the leader is learned rather than memorised.

tree-sitter highlighting

Eleven grammars built in, re-parsed incrementally as you type — and any other language coloured by a grammar already on the system.

A language-server client

Diagnostics, go to definition, references, rename, code actions, formatting, completion — and a doc box beside the cursor.

lsp-ui-doc new

Rest on a symbol and what the server knows appears beside the line it is about, rather than in a window over the code.

magit

Status, staging by hunk, commits, branches, stashes, log, blame, and the transient menus they hang off.

A file tree

treemacs' keys, git status in the margin, and a side panel that stacks the tree, the symbol outline and the buffer list.

A window, as well as a terminal new

The same editor drawn by the GPU: smooth sub-line scrolling, the mouse, the system clipboard, and any font on the system.

beacon new

A light where the cursor lands after a jump. Off by default; set beacon=#true turns it on.

A terminal panel

A real pseudo-terminal along the bottom, in tabs, running whatever $SHELL says.

Project search, and editing the results

grep the project, then edit the matches in place and write them all back — wgrep.

No Lisp interpreter

Configuration is a small declarative file. Scripting, where you want it, is Rhai. One binary, no runtime to install.

Configured in one file

~/.config/maxgus/config.kdl. Every node is optional, anything left out keeps its default, and a node it does not recognise is reported with a line number and skipped — so a file written for a newer version still starts an older one. 

// ---- settings ----
set theme="maxgus-dark"
set line-numbers=#true
set scroll-margin=3
set which-key=#true
set lsp-doc=#true
set beacon=#true

// ---- keys ----
keymap "global" {
    bind "C-c f" "lsp-format-buffer"
    unbind "C-z"
}
// ---- faces ----
theme "maxgus-dark" {
    face "font-lock-comment" fg="#5f6b73" italic=#true
    face "region" bg="#3a4048"
}

// ---- language servers ----
lsp "rust" command="rust-analyzer" {
    root-markers "Cargo.toml"
}

Getting going

Open a file and press C-h t for a guided tour, or C-h b to list every binding. C-x C-c leaves.

If C-c is a prefix you do not know yet, hold it: the panel will tell you what is under it.

The README is the long version; the reference lists every setting, face and key.

$ maxgus src/main.rs         # a terminal
$ maxgus -nw src/main.rs     # a terminal, from a gui build
$ maxgus --version
maxgus 0.2.1 (full)

# Install somewhere else, or an older release:
$ curl -fsSL …/install.sh | sh -s -- \
    --prefix /usr/local/bin --version v0.1.0
